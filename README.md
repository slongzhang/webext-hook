# webext-hook

**面向浏览器插件开发的主世界 Hook 解决方案**，专为浏览器扩展（WebExtension）设计，解决插件隔离环境无法直接劫持主世界原生接口的痛点，轻量、无侵入、易扩展。

本项目致力于封装一套完整的主世界常用 API 劫持能力，适配各类浏览器插件业务场景（接口请求篡改、数据监听、请求拦截、数据格式化劫持等）。

## ✨ 项目特性

- **专属插件场景**：针对性解决浏览器插件沙箱隔离问题，精准劫持页面主世界原生方法，规避插件环境限制

- **模块化可扩展**：统一 Hook 架构，可按需启用 XHR、Fetch、Request、JSON 系列劫持能力

- **轻量无侵入**：源码简洁，零外部冗余依赖，劫持逻辑纯净，不污染原生全局环境

- **高兼容性**：适配 Chromium、Edge、Chrome 等主流内核浏览器，兼容绝大多数插件开发场景

## 📌 能力规划

项目计划支持 5 类核心原生 API Hook，覆盖前端高频劫持场景，迭代进度如下：

|Hook 能力|状态|能力说明|
|---|---|---|
|XMLHttpRequest（XHR）|✅ 已完成（基于 ajax\-hook 实现）|劫持原生 XHR 请求，支持请求/响应拦截、参数篡改、异常监听|
|Fetch|⏳ 开发中|劫持原生 Fetch 网络请求，适配现代化请求场景|
|Request|⏳ 开发中|劫持 Request 请求对象，精细化拦截请求配置|
|JSON\.parse|⏳ 开发中|劫持 JSON 解析方法，监听/篡改全局解析数据|
|JSON\.stringify|⏳ 开发中|劫持 JSON 序列化方法，拦截全局数据序列化行为|
